# Assignment 4. Forms and Validation

**Student:** Nurzhan Aisu 
**Group:** SE-2530
**Course:** Web Technologies (Front-End), Astana IT University

## Description
A small multi-page website about HTML forms, HTML5 validation and Bootstrap 5 forms.
Every page has the same navbar, so you can move between tasks.

| Page | Task |
|------|------|
| `index.html` | Home page with links to all tasks |
| `task0-contact.html` | Task 0. Simple contact form with labels |
| `task1-validation.html` | Task 1. HTML5 validation (required, type, minlength, maxlength, pattern, min/max) |
| `task2-bootstrap.html` | Task 2. Contact form with Bootstrap classes and grid, placeholders, helper text |
| `task3-feedback.html` | Task 3. Bootstrap `is-valid` / `is-invalid` with `valid-feedback` / `invalid-feedback` messages |
| `task4-registration.html` | Task 4. Registration form (inputs, passwords, radio, checkbox, select, Submit/Reset) with HTML5 validation |

## Technologies
HTML5, CSS3, Bootstrap 5.3 (CDN). No custom JavaScript: validation uses HTML5 attributes and Bootstrap classes.

## How to run
1. Download or clone the repository.
2. Open `index.html` in a browser (internet is needed for Bootstrap CDN).
